# 🎧 AudioControl Central

**Глобальные горячие клавиши для громкости отдельных приложений и управления их плеером — на Windows.**

Убавить звук Яндекс Музыки, не трогая Discord и браузер. Поставить трек на паузу именно в том приложении, которое вы настроили, даже если музыка играет ещё где-то. Всё работает из любого окна, пока программа висит в трее.

## Возможности

- **Громкость по приложениям.** Каждому процессу — свой набор хоткеев: громче, тише, mute. Шаг изменения настраивается (по умолчанию 10%).
- **Медиаклавиши, привязанные к приложению.** Play/Pause, следующий и предыдущий трек управляют *именно вашим* приложением, а не тем, которое Windows считает «текущим». Если играют два плеера одновременно — каждый профиль управляет своим.
- **Проверка конфликтов.** Если комбинация уже занята другим профилем или другой программой, вы увидите это сразу, а не «хоткей молча не работает».
- **Диагностика.** В настройках видно, какие комбинации Windows приняла, а какие отклонила. У действий громкости есть кнопка «Проверить» — выполнить прямо сейчас, без нажатия хоткея.
- **Работа в фоне.** Сворачивается в трей, оттуда же можно включить/выключить все хоткеи разом.
- **Два языка интерфейса** — русский и английский, переключаются на лету.
- **Автозапуск с Windows** — одной галочкой, без прав администратора.

## Установка

1. Откройте [страницу релизов](https://github.com/zvshkin/AudioControl/releases/latest).
2. Скачайте `AudioControl-vX.Y.Z-windows-amd64.exe`.
3. Запустите. Установка не требуется — это portable-файл.

> SmartScreen может предупредить о неизвестном издателе: сборка не подписана сертификатом, это нормально для небольших open-source проектов. **«Подробнее» → «Выполнить в любом случае»**.

### Требования

Windows 10 (1809+) или Windows 11, 64-бит. Устанавливать .NET/Go/что-либо ещё не нужно.

## Быстрый старт

1. Нажмите **«Добавить профиль»** и выберите приложение из списка запущенных процессов.
2. Кликните по полю хоткея и нажмите нужную комбинацию (обязательно с Ctrl/Alt/Shift/Win).
3. Настройте шаг громкости рядом с заголовком «Громкость», если 10% не подходит.
4. Закройте окно крестиком — программа свернётся в трей и продолжит работать.

### Если медиаклавиши не срабатывают

Идентификатор медиа-сессии не всегда совпадает с именем процесса. Откройте в профиле выпадающий список **«Медиа-цель»** и выберите нужную сессию вручную — там перечислены все, что сейчас видит Windows.

## Сборка из исходников

```bash
git clone https://github.com/zvshkin/AudioControl.git
cd REPO

cd frontend && npm install && cd ..
wails dev     # запуск в режиме разработки
wails build   # сборка .exe в build/bin/
```

Нужны [Go](https://go.dev/dl/) 1.25+ (версия зафиксирована в `go.mod`), [Node.js](https://nodejs.org/) 18+ и [Wails CLI](https://wails.io/docs/gettingstarted/installation):

```bash
go install github.com/wailsapp/wails/v2/cmd/wails@latest
```

### CI и релизы

На каждый push и pull request GitHub Actions (`.github/workflows/ci.yml`) прогоняет `gofmt`, `go build`, `go vet`, `go test` и сборку фронтенда — на раннере `windows-latest`, потому что проект завязан на Win32.

Релиз собирается автоматически: запушьте тег `vX.Y.Z`, и release-workflow соберёт `wails build` и опубликует `AudioControl-vX.Y.Z-windows-amd64.exe` на странице релизов. Полная инструкция по релизу — в [RELEASE.md](RELEASE.md).

## Как это устроено

| Пакет | Назначение |
|---|---|
| `hotkey/` | Регистрация глобальных хоткеев через `RegisterHotKey`, выделенный поток с циклом сообщений |
| `audio/` | Громкость и mute по процессам через WASAPI (`IAudioSessionManager2`) |
| `media/` | Управление конкретной медиа-сессией через WinRT `GlobalSystemMediaTransportControlsSessionManager` |
| `process/` | Список запущенных процессов с иконками |
| `config/` | Конфиг в `%AppData%\AudioControl\config.json`, атомарное сохранение |
| `tray/` | Иконка и меню в системном трее |
| `autostart/` | Автозапуск через `HKCU\...\Run` |
| `frontend/` | Интерфейс на React + TypeScript + Tailwind |
